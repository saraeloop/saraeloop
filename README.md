Hi, I'm Sara.

I'm a software engineer and the founder of **[Synthesis](https://synthesis.engineering)**, a computational studio building secure software, immersive web experiences, and agentic systems as one connected practice.

My research is in AI governance, which I'm building as [Noēsis](https://github.com/saraeloop/noesis), a runtime that makes agent execution traceable, replayable, and governable. I also shipped [Prism](https://www.npmjs.com/package/@synthesisengineering/prism), a native HTML-in-Canvas runtime; [depgraph-cli](https://github.com/synthesiseng/depgraph-cli), a behavior-based npm dependency scanner; and [gitrole](https://docs.gitrole.dev), a Git identity switcher. I'm currently building [pixipix](https://github.com/pixipixhq/pixipix).


When I'm not building, I'm usually taking apart hardware I bought "just to see," or negotiating desk space with my cat, Poppy.
