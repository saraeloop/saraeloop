Hi, I'm Sara.

I'm a software engineer and the founder of **[Synthesis](https://synthesis.engineering)**, a computational studio building secure software, immersive web experiences, and agentic systems.

My research is in AI governance through [Noēsis](https://github.com/saraeloop/noesis), a runtime for traceable, replayable, and governable agent execution. I shipped [Prism](https://www.npmjs.com/package/@synthesisengineering/prism), a native HTML-in-Canvas runtime, and I'm building [pixipix](https://github.com/pixipixhq/pixipix), a deterministic pixel-art processing CLI. My developer tools include [gitrole](https://docs.gitrole.dev/), a Git identity switcher, and [depgraph-cli](https://github.com/synthesiseng/depgraph-cli), a behavior-based npm dependency scanner.

When I'm not building, I'm usually taking apart hardware I bought "just to see," or negotiating desk space with my cat, Poppy.
