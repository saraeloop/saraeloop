Hi, I'm Sara.

I'm a software engineer and the founder of **[Synthesis](https://synthesis.engineering)**, a computational studio building secure software, immersive web experiences, and agentic systems as one connected practice.

My research is in AI governance: making agent execution traceable, replayable, and governable. I'm building it as **[Noēsis](https://github.com/saraeloop/noesis)**, a governance runtime for AI agents. Every run produces immutable evidence. Every phase of reasoning has structure. Every boundary is enforced. The thesis: intelligent software should behave like real software — observable, reproducible, secure, and safe to ship.

Alongside it, I shipped [Prism](https://www.npmjs.com/package/@synthesisengineering/prism), a native HTML-in-Canvas runtime for interfaces that behave like environments; [depgraph-cli](https://github.com/synthesiseng/depgraph-cli), an npm dependency scanner that flags behavioral anomalies instead of matching signatures; and [gitrole](https://docs.gitrole.dev), which switches your entire Git identity in one command. I'm currently building [pixipix](https://github.com/pixipixhq/pixipix). Tiny poses in, tidy pixels out.

When I'm not building, I'm usually taking apart hardware I bought "just to see," or negotiating desk space with my cat, Poppy.
